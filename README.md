# Cartilha: Pedido de Uniformização Nacional x Pedido de Uniformização Regional ;)

## 📒 Descrição
Objetiva-se com a cartilha elencar os principais conceitos e requisitos desses tipos de recursos e diferenciar o cabimento de um e outro.

## 🤖 Tecnologias Utilizadas
Foi utilizado o "GEMINI" para envio de prompt de comando a fim de montar a estrutura teórica da cartilha.
Também foi utilizado "Leonardo IA" para gerar uma capa bonita e inspiradora. 

## 🧐 Processo de Criação
O mais difícil foi compreender como utilizar o git e github, sendo que esse conteúdo foi complementado com vídeos do youtube, além do curso. Após isso, a criação do prompt e retorno das informações pela IA generativa foram de rápida elaboração e obtenção de retorno, o qual após leitura percebeu-se que possui alto grau de compatibilidade com as informações constantes na Lei.
